# AI Prompts & Chat Logs

This file contains the raw AI-assisted development conversations used during
the development of the AutoVault Car Dealership Inventory System.

The purpose of this file is to provide transparency about how AI tools were
used during the development process, as required by the project specification.

> IMPORTANT:
> The conversations below are included as raw, unedited chat logs.
> No AI-generated summary has been substituted for the original conversations.

---

# AI Tool Usage

## Tool Used

- ChatGPT

## Purpose

ChatGPT was used as a development assistant during different stages of the
project, including:

- Project architecture discussions
- React UI development
- Backend API development
- Authentication implementation
- JWT authentication debugging
- Vehicle inventory implementation
- MongoDB integration
- API debugging
- Frontend/backend integration
- Bug fixing
- UI improvements
- README documentation
- Git and GitHub workflow guidance
- Test and project-structure guidance

The developer reviewed, modified, integrated, and tested the generated
suggestions before using them in the project.

# Development Notes

The AI assistant was used as a development aid rather than as a replacement
for developer decision-making.

The developer remained responsible for:

- Reviewing generated code
- Integrating the code into the existing project
- Resolving compilation/runtime errors
- Testing API endpoints
- Testing frontend functionality
- Verifying database operations
- Making final architectural decisions
- Reviewing security considerations
- Managing the Git repository
- Preparing the final project submission
